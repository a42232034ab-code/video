# 台本 × 画像 動画メーカー

台本(テキスト)をまとめて貼り付けて、背景・キャラクター画像を用意するだけで、長尺の2人掛け合いナレーション動画(いわゆる「ゆっくり解説」風)を自動生成する Web アプリです。

## 主な機能

- 台本をまとめて貼り付けて、「話者名: セリフ」形式で自動的に行に分割
- 話者A・話者B の2人掛け合いに対応(名前・声・キャラクター画像をそれぞれ設定可能)
- 背景画像・キャラクター画像は動画全体で使い回されるため、行ごとに画像を用意する必要はなし(行ごとに個別の画像で上書きすることも可能)
- キャラクター画像は話しているとき、画面下部の左(話者A)/右(話者B)に自動表示
- テキストから音声ナレーションを自動生成([espeak-ng](https://github.com/espeak-ng/espeak-ng) によるオフライン音声合成、話者ごとに声を変更可能)
- 台本テキストを字幕として動画に焼き込み
- 背景をゆっくりズームする Ken Burns 風エフェクト(任意)
- 16:9 / 9:16 / 1:1 の画面比率に対応(YouTube・ショート動画・正方形投稿など)
- BGM のアップロードとミックス(音量調整可)
- 生成状況をリアルタイムに表示し、完成後はブラウザでプレビュー・ダウンロード
- 1 ジョブあたり最大 300 行までの長尺動画に対応

## セットアップ

### 前提

- Node.js 18 以上
- [espeak-ng](https://github.com/espeak-ng/espeak-ng)(ナレーション生成に使用。無くても動作しますが、その場合は無音+字幕のみの動画になります)
- 日本語(CJK)フォント(字幕を正しく描画するために必要。例: `fonts-noto-cjk`)

Debian/Ubuntu の場合:

```bash
sudo apt-get update
sudo apt-get install -y espeak-ng fonts-noto-cjk
```

macOS の場合:

```bash
brew install espeak-ng
# macOS には標準で日本語フォントが入っています
```

### インストールと起動

```bash
npm install
npm start
```

ブラウザで `http://localhost:3000` を開いてください。

環境変数 `PORT` でポート番号を変更できます。

### Docker で実行

依存関係(ffmpeg・espeak-ng・日本語フォント)を含めてすぐに動かせる Dockerfile を用意しています。

```bash
docker build -t script-to-video .
docker run -p 3000:3000 script-to-video
```

## 使い方

1. 「話者・背景」パネルで、背景画像(任意)と話者A/話者Bの名前・声・キャラクター画像(任意)を設定します。
2. 「台本」パネルに台本をまとめて貼り付けます。設定した話者名と一致する「話者名: セリフ」形式の行はその話者に、それ以外はナレーションとして扱われます。

   ```
   霊夢: こんにちは、今日は○○について解説していくよ。
   魔理沙: おー、楽しみだぜ。
   霊夢: まずは基本から説明するね。
   ```

3. 「解析して行を追加」を押すと、「行一覧」に編集可能な行として追加されます。話者の変更・並べ替え・削除、行ごとの画像上書き(任意)もここで行えます。
4. 右側の設定パネルで、ナレーションの有無・字幕表示・画面比率・ズーム効果・BGM を設定します。
5. 「動画を生成する」を押すと、サーバー側で行ごとに動画クリップを作成し、結合して1本の動画に仕上げます。
6. 完成すると自動でプレビューが表示され、ダウンロードできます。

## 仕組み(技術メモ)

- サーバー: Node.js + Express。アップロードは `multer` で受け取ります。
- 動画生成: [`ffmpeg-static`](https://www.npmjs.com/package/ffmpeg-static) にバンドルされた ffmpeg バイナリを使用するため、システムに ffmpeg をインストールする必要はありません。
- 各行は「背景画像(+ 話者のキャラクター画像を overlay 合成、または行専用の画像)+ ナレーション音声(または無音)+ 字幕」を個別に mp4 にレンダリングし、最後に結合(concat)します。長尺動画向けに `libx264 veryfast` プリセットでエンコードします。
- 字幕は libass の `FontSize` が `PlayResY` に対して相対スケールされる仕様のため、`PlayResX/PlayResY` を動画解像度に明示指定した ASS ファイルを自前生成し、解像度に依存せず正確なサイズ・折り返しを実現しています。
- ナレーションを使わない場合は、文字数から読み上げ時間を推定して行の表示時間を決定します。
- 生成済みの動画・アップロード済みファイルは `data/` 以下に保存され、一定時間後に自動的にクリーンアップされます。

## 制限事項

- ナレーションは espeak-ng によるオフライン合成のため、機械音声的な読み上げになります(自然な音声合成 API とは音質が異なります)。
- 話者は最大2人(話者A・話者B)+ ナレーションまでです。
- 1 ジョブあたり最大 300 行までです。
